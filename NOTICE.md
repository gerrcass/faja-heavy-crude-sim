## Anatomy

This project vendors the isometric drawing kit and verification scripts from **Anatomy** by Ryan Wheres:

- Source: https://github.com/wheresryan22/anatomy
- License: MIT
- Copyright: the Anatomy contributors

Vendored kit files:

- `src/iso/iso-kit.ts` and `src/iso/iso-kit.mjs` — camera, solids, parts library, SVG renderer, plate card and CSS
- `src/iso/lathe.mjs` — turned parts on any axis
- `src/iso/tube.mjs` — pipes, tubes and cables
- `src/iso/iso.css` — the kit stylesheet

Vendored verification scripts:

- `tools/anatomy/capture.mjs`, `drive.mjs`, `lines.mjs`, `chrome-port.mjs`, `line-ends.mjs`, `inline-kit.mjs`
