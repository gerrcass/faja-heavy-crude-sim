# Triage labels

The skills use five canonical triage roles. This repo uses the same strings as its GitHub labels.

| Role | Label | Meaning |
|---|---|---|
| Needs evaluation | `needs-triage` | Maintainer has not evaluated this yet |
| Needs information | `needs-info` | Waiting on the reporter |
| Ready for an agent | `ready-for-agent` | Fully specified and safe for an AFK agent |
| Ready for a human | `ready-for-human` | Requires human judgement or access |
| Will not action | `wontfix` | Closed without action |
