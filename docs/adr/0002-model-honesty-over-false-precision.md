# Model honesty over false precision

The simulator is an explanatory systems model, not a reservoir simulator. We will keep its inputs and outputs inside published ranges, make every output monotone in the direction the physics requires, show the assumptions beside the controls, and label generated numbers as illustrative. This is preferable to a more "realistic" black box: the audience needs to see which lever moves which constraint, and a model that hides its assumptions would teach the wrong lesson about trust.
